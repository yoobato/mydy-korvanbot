# KoreaVancouverBot

주밴쿠버 대한민국 총영사관 홈페이지의 새 게시글을 텔레그램으로 알려주는 비공식 알림 서비스입니다.

[채널 구독](https://t.me/korea_vancouver) · [봇](https://t.me/KoreaVancouverBot)

## 모니터링 게시판

- 공지사항
- 순회영사
- 해외여행안전정보
- 동포/지역한인회 소식

모니터링 대상과 확인 주기는 `boards.json`에서 설정합니다.

## 동작 원리

1. 10분마다 게시판의 최근 3페이지를 확인합니다. 공지사항은 공식 RSS도 함께 읽습니다.
2. 처음 확인한 게시글은 기록만 하고, 이후 새로 발견한 글부터 알림을 보냅니다.
3. 게시글 본문을 읽어 게시판 이름, 제목, 게시일, 짧은 본문 요약, 원문 링크를 채널에 올립니다.
4. 전송 기록을 저장해 재시작 후 중복 알림을 줄이고, 전송 실패 시 다음 확인에서 다시 시도합니다.

제목 수정은 새 알림을 만들지 않습니다. 같은 공지가 여러 게시판에 올라오면 각각 알림을 보냅니다.
요약은 본문 도입부와 일시·장소·신청 안내를 최대 320자로 발췌합니다. 이미지로만 작성된 글은 원문 이미지 확인 안내를 표시합니다.
오랜 중단으로 조회 범위를 벗어난 글은 놓칠 수 있고, 전송 응답이 유실되면 중복 알림이 발생할 수 있습니다.

설정값 예시는 `.env.example`에 있습니다. 실제 `.env`와 게시글 기록은 저장소에 포함하지 않습니다.
