새 글과 수정된 글
처음 확인한 기존 글은 보내지 않고, 이후 새로 발견한 글부터 알려드립니다. 제목이나 본문이 바뀌면 ‘📝 게시글 수정’ 알림을 따로 보내드립니다. 수정 여부를 처음 확인하는 글은 현재 내용을 기준으로 저장합니다.
오류가 발생하면
게시글 수집이나 알림 전송에 실패하면 다음 확인 주기에 다시 시도합니다.
확인 주기
게시판 확인을 마치면 60분 뒤에 다시 확인합니다. 최근 목록의 글은 매번 수정 여부도 확인하고, 목록에서 벗어난 저장된 글은 하루 한 번 다시 읽습니다. 게시 시점과 알림 시점에는 차이가 있을 수 있어요. 홈페이지 연결이 끊기거나 구조가 바뀌면 알림이 늦어지거나 일부 글을 놓칠 수 있습니다.
이미지와 첨부파일
이미지 속 글자와 첨부 PDF·문서는 읽지 않습니다. 같은 주소의 이미지·파일 내용만 바뀐 경우나 별도 첨부파일의 변경은 감지하지 못합니다. 이미지뿐인 글은 원문 확인 안내를 보내드리니, 자세한 내용은 원문을 확인해 주세요.
